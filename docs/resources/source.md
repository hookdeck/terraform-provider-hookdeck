# hookdeck_source (Resource)

~> **Deprecated.** `hookdeck_source` is the v2 name of [`hookdeck_gateway_source`](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/resources/gateway_source) and will be removed in v4. Rename it with a `moved` block; nothing is recreated. See the [v2 to v3 migration guide](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/guides/v2-to-v3-migration).

Both names take the same arguments. Examples and import instructions are on the [`hookdeck_gateway_source`](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/resources/gateway_source) page.
