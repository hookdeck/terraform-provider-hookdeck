# hookdeck_source (Resource)

~> **Deprecated.** `hookdeck_source` is the v2 name of [`hookdeck_gateway_source`](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/resources/gateway_source) and will be removed in v4. Rename it with a `moved` block; nothing is recreated. See the [v2 to v3 migration guide](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/guides/v2-to-v3-migration).

Both names take the same arguments. Examples and import instructions are on the [`hookdeck_gateway_source`](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/resources/gateway_source) page.

## Schema

### Required

- `name` (String) A unique, human-friendly name for the source

### Optional

- `config` (String, Sensitive) Source configuration as JSON. Leave `auth` out when `hookdeck_gateway_source_auth` manages the source's authentication. Only the keys you set are compared with Hookdeck; a change made outside Terraform to one of them shows in the plan, and the next apply restores your value. Other keys, including defaults Hookdeck adds, are kept in state and not compared. Removing a key clears it in Hookdeck, with the exceptions in the guide. State holds everything Hookdeck returns, including secrets such as authentication tokens. See [Source and destination config](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/guides/config).
- `description` (String) Description for the source
- `project_id` (String) ID of the project the resource belongs to. With a project API key or a provider `project_id`, every resource is in that project and this can be omitted. With an organization API key and no provider `project_id`, it is required. Changing it replaces the resource.
- `type` (String) Type of the source

### Read-Only

- `created_at` (String) Date the source was created
- `disabled_at` (String) Date the source was disabled
- `id` (String) ID of the source
- `team_id` (String) ID of the project the resource belongs to. Same value as `project_id`.
- `updated_at` (String) Date the source was last updated
- `url` (String) A unique URL that must be supplied to your webhook's provider
