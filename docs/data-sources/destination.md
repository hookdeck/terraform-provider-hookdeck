# hookdeck_destination (Data Source)

~> **Deprecated.** `hookdeck_destination` is the v2 name of [`hookdeck_gateway_destination`](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/data-sources/gateway_destination) and will be removed in v4. Rename it in your configuration. See the [v2 to v3 migration guide](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/guides/v2-to-v3-migration).

Both names take the same arguments. Examples and import instructions are on the [`hookdeck_gateway_destination`](https://registry.terraform.io/providers/hookdeck/hookdeck/latest/docs/data-sources/gateway_destination) page.
