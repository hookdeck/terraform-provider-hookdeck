# hookdeck_outpost_project (Data Source)

Outpost project, looked up by ID or name.

Unlike the `hookdeck_outpost_project` resource, whose `config` and `sensitive_config` hold the keys you manage, `config` here holds the whole configuration of the project, defaults included.

~> `config` is sensitive because it can include secrets, and it is stored in the Terraform state, even when the data source is only used to look up a project's ID. Protect the state as you would for any secret. To use a value that is not a secret in an output, wrap it in `nonsensitive()`.

Works with an organization API key (`projects.read`) or the project's own API key.

## Example Usage

```terraform
data "hookdeck_outpost_project" "by_id" {
  id = "tm_xxx"
}

data "hookdeck_outpost_project" "by_name" {
  name = "production-outpost"
}

# The whole configuration is readable, including values you did not set.
# config is sensitive; wrap a value that is not a secret in nonsensitive() to output it.
output "max_retry_limit" {
  value = nonsensitive(data.hookdeck_outpost_project.by_name.config["MAX_RETRY_LIMIT"])
}
```

### Optional

- `id` (String) ID of the project. One of `id` or `name` is required.
- `name` (String) Name of the project. One of `id` or `name` is required; the name must be unique among the Outpost projects the API key can see.

- `organization_id` (String) ID of the organization the project belongs to
- `type` (String) Project type, always `outpost`
